# Synthace

> Synthace is a life-science software company behind Antha, a cloud digital-experiment
> platform for R&D teams. Biologists use it to design multifactorial Design of Experiments
> (DOE) and Quality by Design (QbD) studies, simulate them before running, compile them into
> machine-executable protocols that drive third-party lab automation hardware, and capture the
> resulting experimental data and metadata as a single structured, AI-ready record.

## API status

Synthace publishes **no public API**. As of 2026-08-29 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK on any package registry, and no MCP
server or agent card. The Antha platform application at https://antha.com serves an
authenticated API at `/api/*` that answers every unauthenticated request with
`{"error":"Unauthorized"}` (HTTP 401). Access requires an active Synthace tenant. Do not
attempt to call it without credentials, and do not assume any endpoint shape - none is
published.

If you need programmatic access, the contact path is https://www.synthace.com/contact-us.
